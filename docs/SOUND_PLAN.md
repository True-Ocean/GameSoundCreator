# 音質・音色の実装方針

Phase 0〜3 で「生成〜試聴〜書き出し」の土台はできた。  
本文書は、**ピクセルバトル投入前に目指す音の品質**と、そのための実装順を固定する。

---

## 1. 当面の音質ゴール

### 目指すもの

**レトロゲームの BGM として違和感なく使えるレベル**（おおよそ 16ビット〜初期インディーのシンセ曲）。

- ループが小節頭で自然につながる（実装済みの方針を維持）
- 雰囲気（明るい／緊張／暗い）が耳で分かる（強化済み、今後も維持）
- 楽器（音色）を変えると役割が分かる
- 完全ローカル・手続き生成・外部AIなし

### 目指さないもの（今はやらない）

- 映画級オーケストラ
- 商用サンプルライブラリ並みのリアルさ
- クラウド生成AI
- 大規模オンデバイス ML

### 品質段階（目安）

| 段階 | 内容 | 状態 |
|------|------|------|
| 出発点 | 単純波形中心（チップチューン寄り） | 現状に近い |
| 次 | 楽器差（ピアノ／パッド／ベース等） | **これから** |
| **ゴール（当面）** | **簡易FM・フィルタ・短い残響・レイヤー増** | **Phase 3.5 で到達** |
| 将来 | 小さな自作／商用可サンプルの同梱 | Phase 6 以降で再評価 |

## 2. 楽器（音色）方針

ウィザードに **「音色」** 選択を追加する（BGM優先。SEは後続）。

### 最初に入れる4種（必須）

| ID（案） | 表示名 | 用途 |
|----------|--------|------|
| `lead_synth` | シンセリード | 戦闘メロディ。現行に近いが整理して残す |
| `piano` | ピアノ風 | メニュー・結果・汎用 |
| `pad` | パッド／ストリングス風 | コードの厚み・雰囲気 |
| `bass` | ベース | 低音の土台（専用音色として明確化） |

### 直後に足す候補

| ID（案） | 表示名 | 用途 |
|----------|--------|------|
| `organ` | オルガン風 | 荘厳・ファンタジー寄り |
| `guitar` | ギター風 | 明るめ・カジュアル |
| `bell` | ベル／プラック | 短いフレーズ・キラキラ |

UIはゲームの言葉で出す（「波形名」ではなく「ピアノ風」など）。

---

## 3. 合成エンジンの強化項目

ゴール到達に必要な技術要素:

1. **楽器エンベロープ**  
   ピアノ＝速いアタック＋減衰、パッド＝遅いアタック、など
2. **簡易FM**  
   ベルや厚み、リードの金属感
3. **フィルタ**  
   ローパス等で暗さ／明るさを音色側でも表現
4. **短い残響（リバーブ）**  
   乾いた8bit感を和らげ、レトロコンソール〜初期インディー寄りの空間に
5. **レイヤー**  
   例: パッド＋リード＋ベースを同時に、楽器選択に応じて割当

ドラムは現行の合成キック／スネア／ハットを基本とし、生ドラム化は急がない。

---

## 4. 実装順（Phase 3.5）

ピクセルバトル投入（Phase 4）の前に、次の順で進める。

| Step | 内容 | 完了の目安 |
|------|------|------------|
| **3.5-A** | 音色カタログ＋Intent/Recipe 配線＋UI選択 | 音色を変えると差が分かる |
| **3.5-B** | 4楽器のエンベロープ／倍音設計 | ピアノ≠パッド≠リードが明確 |
| **3.5-C** | フィルタ＋短い残響 | チップチューン感が明らかに減る |
| **3.5-D** | 簡易FM＋レイヤー割当の整理 | レトロゲーム曲として仮置き耐える |
| **3.5-E** | （任意）オルガン／ギター等の追加 | 必要になってから |

各 Step のあとに実機で「戦闘／メニュー」を聴き、ピクセルバトルに載せる判断材料にする。

---

## 5. プロダクト上の位置づけ

```
Phase 0–3     土台（生成・UI・ループ・雰囲気）
Phase 3.5     レトロゲーム品質への音色・合成強化  ← いまの注力
Phase 4       ピクセルバトルへ投入
Phase 5       App Store 販売準備
Phase 6+      ジャンル拡充・サンプル・バッチ書き出し等
```

音数が足りない・用途が少ない問題は、Phase 3.5 と並行／直後に **ピクセルバトル必須イベントから** カタログを増やす（全部を先に埋めない）。

---

## 6. 成功指標（Phase 3.5 完了）

- [ ] 音色4種を選ぶと、同じシーンでも聴感が大きく違う
- [ ] 「8ビットそのもの」ではなく、レトロコンソール〜初期インディー寄りの印象になる
- [ ] フィルタ／短い残響がオンでも、ループ継ぎ目が破綻しない
- [ ] 生成時間が実機で許容内（目安: 数十秒ループが数秒以内）
- [ ] ピクセルバトル担当者が「仮置きして遊べる」と判断できる
