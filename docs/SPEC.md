## 1. 概要

### 1.1 プロダクト定義

**GameSoundCreator** は、ゲーム向けの BGM および効果音を、**端末内だけで手続き的に生成・試聴・書き出し**できるアプリである。

ユーザーは音楽の専門パラメータではなく、**使う場所・用途・音色イメージ・雰囲気・長さ**といった制作上の意図を選ぶ。アプリがその意図を内部の生成レシピ（Recipe）に変換し、マッチした音を出す。

- 外部の生成AI API・クラウド推論は使用しない
- オフラインで完結する
- 自作ゲーム用アセット制作ツールとして先に実用化し、その後 App Store で一般向けに販売する

### 1.2 解決する課題

| 課題 | 本製品の答え |
|------|----------------|
| 商用BGM/SEのライセンス費用・探索コスト | 自前生成で量産 |
| AI音楽サービスの通信・課金・利用制限 | 完全ローカル |
| 「ゲームっぽい」短いループとSEの不足 | 用途カタログに特化した意図選択 |
| 音楽知識がないと作れない | ジャンル／シーン／雰囲気の言葉だけで操作 |
| エンジニアが音なしで開発を進められない | 数タップで試聴・書き出し |

### 1.3 非目標（初期リリースではやらないこと）

- 映画級・フルオーケストラの長尺作曲
- 歌声・ボーカル生成
- クラウド同期・マルチユーザー共同編集
- 既存楽曲の解析・模倣（著作権リスク）
- Android 同時リリース（iOS 安定後に再評価）
- あらゆるジャンル×シーンの網羅的・プロ級マッチ（カタログは段階的に拡充）

### 1.4 UX の中核方針

本製品の UI は **DAW（音楽制作ソフト）ではなく、ゲーム用途のカタログ＋ウィザード** である。

```
使う場所 × 用途 × 音色イメージ × 雰囲気 × 長さ
        ↓
     Intent（意図）
        ↓
 Intent → Recipe マッパー
        ↓
   生成 → 試聴 → 別パターン / 書き出し
```

ユーザーが普段触るのは Intent。BPM・波形名・コード進行などの技術パラメータは「微調整」に隠し、必須操作にしない。

## 2. ユーザーと利用シナリオ

### 2.1 プライマリユーザー（自分）

自作カードバトルアプリ向けに、ジャンル／シーン／用途を選んで BGM・SE を生成し、ファイルとして書き出す。

### 2.2 セカンダリユーザー（App Store 購入者）

インディー開発者・趣味のゲーム制作者が、音楽の専門知識なしに「戦闘BGM」「メニューBGM」「ボタン音」などを作り、他プロジェクトへ書き出す。

### 2.3 主要シナリオ

1. **BGM を意図から作る:** 「BGMスタジオ」→ 使う場所「プレイ中」→ 用途「バトル」→ 音色イメージ・雰囲気 → 長さ「中・2メロ」→ 再生 → テンポ等を微調整 → 別パターン or 書き出し
2. **SE を意図から作る:** 「効果音スタジオ」→ カテゴリ「カード」→ 用途「ドロー」→ 雰囲気 →（任意でスライダー）→ 再生 → 書き出し
3. **気に入るまで回す:** 同じ画面で「別パターン」（seed 変更）を繰り返し、保存
4. **微調整:** BGMはテンポ／ピッチ／リズム、SEは高さ／音色／強さ／長さ／音数
5. **セット量産（v1 以降）:** 基本セットを一括生成
6. **自作ゲームへ渡す:** 共有シート / Files で WAV をエクスポート

## 4. 意図モデル（Intent）とカタログ

### 4.1 Intent の定義

Intent は、ユーザーが UI 上で選んだ**制作意図**のまとまりである。シリアライズ可能（JSON）とし、ライブラリ保存・共有の単位にもなる。

| フィールド | 型 | 必須 | 説明 |
|------------|-----|------|------|
| `version` | Int | ○ | Intent スキーマ版 |
| `soundType` | Enum | ○ | `bgm` / `sfx` |
| `genreId` | String | ○ | ゲームジャンル |
| `sceneId` | String | BGM時○ | BGM の使用シーン |
| `purposeId` | String | SE時○ | SE の UI／アクション用途 |
| `moodId` | String | ○ | 雰囲気（既定値可） |
| `lengthId` | String | ○ | 長さプリセット（既定値可） |
| `seed` | UInt64? | — | 未指定なら生成時に抽選 |

BGM では `sceneId` を使い `purposeId` は空。SE では `purposeId` を使い `sceneId` は空（または用途から暗示されるシーンを内部保持してもよい）。

#### Intent の JSON 例（BGM）

```json
{
  "version": 1,
  "soundType": "bgm",
  "genreId": "card_battle",
  "sceneId": "battle_normal",
  "moodId": "tense",
  "lengthId": "sec_30",
  "seed": 42
}
```

#### Intent の JSON 例（SE）

```json
{
  "version": 1,
  "soundType": "sfx",
  "genreId": "card_battle",
  "purposeId": "card_draw",
  "moodId": "neutral",
  "lengthId": "sfx_short",
  "seed": 7
}
```

### 4.2 変換パイプライン

```
Intent
  → CatalogLookup（ジャンル／シーン／用途のテンプレ取得）
  → MoodLengthApply（雰囲気・長さを数値に反映）
  → Recipe（エンジン入力）
  → AudioBuffer / File
```

マッパーは App 層ではなく **エンジン隣接の純ロジック**（Swift Package 内）に置き、ユニットテスト可能にする。UI は Intent の組み立てと結果操作に専念する。

### 4.3 ゲームタイプ（`genreId`）

内部互換のために Intent に残す。**BGM スタジオ UI では選択しない**（既定 `card_battle`）。生成時の軽いバイアスにのみ使う。

| ID | 表示名 | UI | 備考 |
|----|--------|----|------|
| `card_battle` | カードバトル | （内部既定） | 既定 |
| `rpg` | RPG | × | ライブラリ互換 |
| `puzzle` | パズル | × | ライブラリ互換 |
| `action` | アクション | × | 準備中 |
| `casual` | カジュアル | × | 準備中 |

### 4.4 BGM 用途（`sceneId`）

BGM は **使う場所 → 用途** の2階層で UI に出す（効果音のカテゴリ→用途と同型）。内部キーは従来どおり `sceneId`。

#### 画面

| ID | 表示名 |
|----|--------|
| `title` | タイトル |
| `menu_main` | メインメニュー |
| `shop` | ショップ |
| `gacha_or_reward` | ガチャ |
| `settings` | 設定 |

#### プレイ中

| ID | 表示名 |
|----|--------|
| `story` | ストーリー |
| `town` | 町／拠点 |
| `adventure` | 冒険 |
| `explore` | 探索 |
| `puzzle` | パズル／思考 |
| `rest` | 休憩 |
| `battle_normal` | バトル |
| `battle_boss` | ボス戦 |

#### 結果

| ID | 表示名 |
|----|--------|
| `result_win` | 勝利 |
| `result_lose` | 敗北 |

ライブラリ互換のため、次の旧 ID は内部に残し UI 非表示。読み込み時は正規化する。

| 旧 ID | 解決先 |
|-------|--------|
| `opening` | `title` |
| `battle_easy` / `battle_hard` / `battle_extra` / `battle_pinch` | `battle_normal` |
| `result_happy_end` | `result_win` |
| `result_bad_end` | `result_lose` |

### 4.6 雰囲気（`moodId`）

| ID | 表示名 | Recipe への主な影響 |
|----|--------|---------------------|
| `bright` | 明るい | 長調寄り、高めピッチ、軽い音色 |
| `neutral` | ふつう | 既定テンプレ |
| `tense` | 緊張 | 短調寄り、energy 高め、密度増 |
| `dark` | 暗い | 短調、ローパス、低域強調 |
| `epic` | 壮大 | 同時発音・低域・ファンファーレ要素 |
| `playful` | 軽快 | 高BPM寄り、短い音符、明るいSE |

MVP では UI 上 **3〜5 択**（例: 明るい / ふつう / 緊張 / 暗い）に絞り、他は v1 で追加してよい。

### 4.7 長さ（`lengthId`）

#### BGM

| ID | 表示名 | 小節 | 展開 | 目安（120BPM） |
|----|--------|------|------|----------------|
| `bars_4` | 短・1メロ | 4 | くり返し | 約8秒 |
| `bars_8` | 中・2メロ | 8 | 起承（A→B） | 約16秒 |
| `bars_16` | 長・4メロ | 16 | 起承転結 | 約32秒 |

内部では **4/4 の小節グリッド**でバッファを生成し、コード進行（4小節周期）の倍数でループする。  
厳密な壁時計の秒数一致より、**小節の頭での自然なループ**を優先する。旧ID（`sec_15` / `bars_24` 等）は互換のため上記へマップする。

#### SE

| ID | 表示名 | 目安 |
|----|--------|------|
| `sfx_short` | 短め | 〜200ms 前後（UIクリック系） |
| `sfx_medium` | ふつう | 200–500ms（既定） |
| `sfx_long` | 長め | 500–1500ms（スキル・ジングル） |

用途ごとに既定の `lengthId` を持ち、ユーザー未変更ならそれを使う。

### 4.8 カタログカバレッジ方針

| 段階 | UI | マッパー／エンジン |
|------|-----|-------------------|
| MVP | カードバトル＋主要シーン／用途を選択可能 | 対応テンプレを実装。未対応は出さない |
| v1 | ジャンル・シーンを拡充 | 組み合わせマトリクスを拡張 |
| 販売後 | 「その他」や要望ベースで追加 | 近いテンプレへのフォールバック可 |

**原則:** UI で選べる組み合わせは、必ず生成できること。未実装の組み合わせを選べて失敗する状態は作らない。

## 5. 効果音仕様

### 5.1 エンジンカテゴリと purpose の対応

用途（`purposeId`）はエンジンカテゴリと **1:1**。近い音へのマップはせず、レトロ合成でも用途ごとに作り分ける。

| 系統 | 例 | 作りの要点 |
|------|----|------------|
| UI | タップ／決定／スワイプ | クリック・上昇／下降ブリップ・ノイズスイープ |
| カード | ドロー／出す／シャッフル／めくる | 紙擦れ、着地thump、連打フラッター、高域スナップ |
| バトル | 通常／強攻撃／斬る／叩く／割る／弓／防御 | 予兆つき大技、ズバッ斬撃、鈍いthump、放ち→飛行→刺突 |
| 魔法 | 炎／氷／毒／嵐／ビーム／回復 | クラックル、凍りつき収縮、泡、広帯域嵐、持続ビーム、明るいARP |
| 動作 | 歩く／走る／飛ぶ／ジャンプ／着地／ダッシュ／泳ぐ／扉 | 足音、空気、バネ上昇、着地thump、加速whoosh、水泡、木製きしみ |
| ガチャ | 回転／レア | 機械ラチェット減速、上昇スパークル＋解放シマー |
| ファンファーレ | 勝利／敗北／ジャジャーン／ピンポーン | テッテレー／デデデーン、和音2打、高→低チャイム |

※ 雰囲気（mood）はピッチ／音色／強さの共通変調。長さは `lengthId` で上書き可能。

### 5.2 SE Recipe パラメータ（エンジン入力）

| パラメータ | 型 | 範囲（目安） | 説明 |
|------------|-----|--------------|------|
| `seed` | UInt64 | — | 再現可能な乱数シード |
| `durationMs` | Int | 50–2000 | 長さ（lengthId から設定） |
| `pitch` | Float | 0.5–2.0 | 基準ピッチ倍率 |
| `timbre` | Float | 0–1 | 音色（ノイズ寄り↔トーン寄り） |
| `intensity` | Float | 0–1 | 強さ・歪み・音量エンベロープ |
| `variation` | Int | 0–7 | 同一カテゴリ内の型違い |

出力: モノラルまたはステレオ、サンプルレート **44100 Hz** または **48000 Hz**（アプリ設定で固定、初期は 44100）。

## 6. BGM 仕様

### 6.1 位置づけと音質ゴール

「名曲」や映画級ではなく、**ループ可能な伴奏＋覚えられるメロディ**でゲームに置ける音を出す。

当面の品質目標は **レトロゲーム BGM レベル**（おおよそ 16ビット〜初期インディー）。  
品質は次の **二軸** で上げる（詳細は [SOUND_PLAN.md](SOUND_PLAN.md)）。

| 軸 | 内容 | Phase |
|----|------|-------|
| 音色・空間 | 楽器差・フィルタ・短い残響・簡易FM・ToneTail／ピアノ専用ボイス | 3.5-C / 3.5-D / 3.5-E（✅） |
| 作曲・メロディ | モチーフ・リズム型・音高輪郭（人間らしい手続き生成） | 3.5-M（M1／M1b ✅） |

非目標: フルオーケストラ、商用サンプル並みのリアルさ、外部生成AI、「名曲」の保証。

### 6.2 用途と初期テンプレ

既存プリセット（`menu_main` / `battle_normal`）をベースに、用途ごとにテンポ・エネルギー・調・既定音色を変調する。  
近い用途（例: タイトルと勝利）は、**音色・テンポ・密度・キー**で耳に分かる差を付ける。

| sceneId | ムード既定 | 既定音色 | ベースプリセット |
|---------|------------|----------|------------------|
| `title` | bright | ピアノ | `bgm.menu.main`（ゆったりテーマ） |
| `menu_main` | bright | ピアノ | `bgm.menu.main` |
| `settings` | neutral | パッド | `bgm.menu.main`（薄い床） |
| `shop` | bright | オルゴール | `bgm.menu.main` |
| `gacha_or_reward` | bright | オルゴール | `bgm.menu.main`（速め・キラキラ） |
| `story` | neutral | オルガン | `bgm.menu.main` |
| `town` | bright | ギター | `bgm.menu.main`（生活ループ） |
| `adventure` | neutral | ギター | `bgm.menu.main`（フィールド） |
| `explore` | neutral | ベース | `bgm.menu.main`（ダンジョン寄り） |
| `puzzle` | neutral | ピアノ | `bgm.menu.main`（思考用・低 energy） |
| `rest` | neutral | パッド | `bgm.menu.main`（セーフルーム） |
| `battle_normal` | tense | シンセリード | `bgm.battle.normal` |
| `battle_boss` | tense | シンセリード | `bgm.battle.normal`（強め） |
| `result_win` | bright | シンセリード | `bgm.menu.main`（短いファンファーレ） |
| `result_lose` | dark | パッド | `bgm.battle.normal` |

### 6.3 BGM Recipe パラメータ（エンジン入力）

| パラメータ | 型 | 範囲（目安） | 説明 |
|------------|-----|--------------|------|
| `seed` | UInt64 | — | 再現性 |
| `tempoBpm` | Int | 80–160 | テンポ（UI: テンポ） |
| `key` | Enum | C, D, … / major\|minor | 調性 |
| `bars` | Int | 4–32 | 尺＋展開（4=1メロ／8=2メロ／16=4メロ） |
| `pitchSemitones` | Int | −6…+6 | 移調（UI: ピッチ） |
| `rhythm` | Float | 0–1 | ドラム／刻みの疎密（UI: リズム） |
| `density` | Float | 0–1 | シーン／雰囲気由来の内部密度 |
| `energy` | Float | 0–1 | シーン／雰囲気由来の内部エネルギー |
| `brightness` | Float | 0–1 | 雰囲気由来（UIなし） |
| `melody` | Bool | — | メロディレイヤー有無 |

### 6.4 音楽構造（エンジン内部）

1. **コード進行テンプレート**（ジャンル／シーン固定の数パターンから seed で選択）
2. **ドラムパターン**（キック / スネア / ハットの簡易シーケンス）
3. **ベース**（ルート＋簡単な歩行）
4. **パッド or コードスタブ**
5. **メロディ**（`MelodyComposer`：雰囲気別モチーフ辞書＋歩幅制約。長さで展開が変わる）
   - 4小節（短・1メロ）: くり返し（モチーフ反復）
   - 8小節（中・2メロ）: 起承（A→対照的なB）
   - 16小節（長・4メロ）: 起承転結（転は密度・リズム・アレンジで対比）
6. **seed 由来の軽い移調**（協和オフセット。major/minor は雰囲気維持）
7. **ループクロスフェード**（書き出し時に継ぎ目を平滑化）

音色はソフトシンセ（サイン／矩形／ノイズ／簡易FM 等）と **音色イメージ**（ピアノ・パッド等）で差別化する。  
品質向上時に小さな自作／商用可サンプルバンクの同梱を再評価する（必須ではない）。

### 6.5 音色イメージ（instrument）— Phase 3.5

スタジオで選択可能（BGM優先）。表示名に「風」は付けない（手続き合成の近似であることは「音色イメージ」ラベルで示す）。

| ID | 表示名 | 備考 |
|----|--------|------|
| `lead_synth` | シンセリード | 矩形波リード。戦闘・勝利ファンファーレ既定 |
| `piano` | ピアノ | 打撃＋倍音段階減衰の専用ボイス。タイトル／メニュー／パズル既定 |
| `pad` | パッド | ゆっくり広がる床。設定・休憩・敗北既定 |
| `bass` | ベース | 低音主役のバランス。探索既定 |
| `music_box` | オルゴール | 金属ティン＋余韻。中高域（刺さらない高さ）。ショップ・ガチャ既定 |
| `organ` | オルガン | 三角波の持続・荘厳。ストーリー既定 |
| `guitar` | ギター | 明るめプラック。冒険・町／拠点既定 |

Intent の `instrumentId` を Mapper 経由で Recipe に渡す。用途未指定時は上表の既定を使う。  
各音色は `InstrumentPalette`（波形・FM・エンベロープ・ToneTail 等）で差別化する。

### 6.6 メロディ作曲（人間らしい手続き生成）— Phase 3.5-M

#### 目的

別パターン（seed 変更）でも「同じランダム連打」に聞こえないこと。  
同じ条件のまま別パターンを押すと、**リズム型またはフレーズ輪郭の差が耳で分かる**こと。  
雰囲気（明るい／ふつう／緊張／暗い）に合った、人が聴いて自然なメロディであること。  
ゲームBGMとして **短い覚えられる塊** があること。

#### 本製品での「人間らしさ」

| 要素 | 要件 |
|------|------|
| モチーフ家族 | 雰囲気別辞書（リズム骨格＋輪郭＋開始音＋尺）から seed で家族を選択 |
| リズム型 | 休符・シンコペ・遅入り等を含む骨格。家族に紐づく |
| 音高輪郭 | 雰囲気ごとに偏らせる（明るい＝上行・安定着地、暗い＝下行 等） |
| ハーモニー | 拍頭は雰囲気別のコードトーン候補へ寄せる。明るいでは導音（相対 −1/−3）を避ける |
| 歩幅 | 隣音中心（おおむね ±2）。大きな跳躍の次は逆方向へ戻る。末尾は安定音着地 |
| 抑揚 | フレーズ頭をやや強く。長さ展開の「転」は高さではなく密度・リズム・ドラムで対比 |
| 移調 | seed による軽い協和移調（モードは雰囲気維持）。別パターンでキー家族が動く |

#### 雰囲気と使える音（要約）

| 雰囲気 | 開始音・拍頭の傾向 | 抑制 |
|--------|-------------------|------|
| 明るい | `0, 2, 4, 7`（安定） | 導音寄り（−1/−3）、転のオクターブ上げ |
| ふつう | 安定中心＋軽い色 | 極端な跳躍連発 |
| 緊張 | `0, 2, 5, −1` 等、跳躍・シンコペ可 | 明るすぎる解決だけ |
| 暗い | 低め・下行、高飛躍を抑制 | キラキラ高音連打 |

#### 長さと展開

| UI | 小節 | フォーム |
|----|------|----------|
| 短・1メロ | 4 | くり返し |
| 中・2メロ | 8 | 起承（A→B） |
| 長・4メロ | 16 | 起承転結（転は密度／リズム／ドラムで対比。リードのオクターブ上げなし） |

#### アーキテクチャ要件

- `MelodyComposer` を **エンジン隣接の純ロジック**として置き、ユニットテスト可能にする
- 生成結果はノート列（相対度数・開始ステップ・長さ・強さ）とし、`BGMEngine` はそれを再生する
- seed はモチーフ家族・進行・軽い移調の選択に使い、家族内は歩幅／着地ルールで整形する
- シーン偏り（戦闘＝energy 高め優先、メニュー＝落ち着き優先）を辞書の並びで反映する
- **UIに作曲用の専門パラメータを増やさない**（既存の seed／雰囲気／密度／音色で効かせる）
- 同一 Intent＋seed なら同一ノート列（再現性）

#### 段階

| Step | 内容 |
|------|------|
| 3.5-M1 | モチーフ＋リズム型＋輪郭（✅） |
| 3.5-M1b | 自然化（導音抑制／転の高さ緩和／雰囲気別音高／歩幅／転の密度対比／モチーフ辞書）（✅ 2026-08-02） |
| 3.5-M2 | コール＆レスポンス／フィル小節のさらなる厚み（任意・フィードバック次第） |

詳細な実装順・成功指標は [SOUND_PLAN.md](SOUND_PLAN.md) を正とする。

### 7.2 レシピ（Recipe）形式

生成エンジンへの入力はすべてシリアライズ可能な **Recipe** とする（JSON）。Intent を保存する場合は、可能なら **Intent と解決済み Recipe の両方**（または Intent＋seed のみ）を残し、カタログ更新後の再現方針をバージョンで管理する。

目的:

- 同じ Recipe から同一音を再生成できる
- 自作カードバトル側に「どのイベントがどの音か」を記録できる
- UI を差し替えてもエンジン資産を保てる

```json
{
  "version": 1,
  "type": "sfx",
  "category": "sfx.attack.light",
  "sourceIntent": {
    "genreId": "card_battle",
    "purposeId": "attack_light",
    "moodId": "tense",
    "lengthId": "sfx_medium"
  },
  "params": {
    "seed": 42,
    "durationMs": 220,
    "pitch": 1.0,
    "timbre": 0.4,
    "intensity": 0.7,
    "variation": 2
  }
}
```

## 8. UI / UX 要件

### 8.1 デザイン原則

| 原則 | 内容 |
|------|------|
| ゲームの言葉で話す | 使う場所・用途・ボタン・ドローなど。BPMや波形名は出さない |
| 条件はスタジオで揃える | ホームはスタジオ入口のみ。BGM／SEとも1画面インライン（グループ→用途） |
| 再生ですぐ聴ける | 再生ボタンが未生成ならその場で生成して再生。「生成して聴く」は置かない |
| 起動はオープニング演出 | © → ブランドロゴ → タイトル＋進捗のあとホーム。音声は裏でウォームアップ |
| BGM生成は明示フィードバック | BGM再生成中は「BGM生成中…」を表示（非同期生成） |
| 微調整は主役のひとつ | BGMのテンポ・ピッチ・リズムは再生中でも裏生成して切替。使う場所／音色イメージ／長さは停止して再生待ち |
| カタログは1画面 | BGM・SEともモーダルなし。スクロール不要を目標 |
| 共有はナビから | 保存・WAV書き出しは右上の共有メニュー |
| BGM と SE を入口で分離 | 長さ・ループの意味が異なるため混在させない |
| 見た目は設定で切替 | テーマカラー: ライム（既定）／アンバー／シアン／マゼンタ／ランダム（起動時に抽選）。選択は端末に保存 |

### 8.2 画面構成

| 画面 | 内容 |
|------|------|
| ホーム | BGMスタジオ / 効果音スタジオ |
| 制作（スタジオ） | 条件（インライン）／微調整／再生・別パターン／共有。スクロール不要を目標 |
| ライブラリ | 再生中心。行タップで制作画面へ。左上「削除」で明示的な削除モード。スワイプ／長押しでも削除 |
| 設定 | テーマカラー切替（ライム／アンバー／シアン／マゼンタ／ランダム）、アプリ情報 |

### 8.3 制作画面詳細

#### BGM スタジオの縦順

1. **構成（停止して再生待ち）:** 使う場所 → 用途 → 音色イメージ → 長さ  
2. **ライブ（再生中は裏生成して切替）:** 雰囲気 → テンポ／ピッチ／リズム → メロディ  
3. **ループ**（再生成なし・再生位置維持で即反映）  
4. 再生バー → 再生／別パターン（横並び。再生中は再生が停止に切替）

- 再生は未生成・条件 dirty なら再生成してから鳴らす
- **別パターン**は **seed だけ**を変え、使う場所／用途／音色イメージ／雰囲気／長さおよびテンポ・ピッチ・リズム・メロディを維持したまま再生成する（モチーフ家族・軽い移調は seed に追随）
- ループ再生はスケジュール連鎖で継ぎ目の無音ギャップを避ける

#### 微調整（インライン）

- SE: 高さ／音色／強さ／長さ／音数（設定変更では鳴らさず、再生／別パターンで反映）
- BGM: テンポ／ピッチ／リズム／メロディは再生中でも旧音を継続しつつ再生成し、完了後に切替（「BGM生成中…」）
- BGM: 使う場所／用途／音色イメージ／長さの変更は再生を停止し、再生ボタンで確定
- BGM: ループは再生成なしで即反映
- 明るさは雰囲気から内部設定（UIスライダーなし）

#### 条件

- BGM・SEとも制作画面にインライン配置（モーダルなし）。スクロール不要を目標
- BGM: 使う場所（画面／プレイ中／結果）→ 用途（UI 15種）→ 音色イメージ → 雰囲気 → 長さ。`genreId` は内部既定
- 雰囲気・長さのセグメントは選択肢が自明なため、見出しラベルは出さず VoiceOver 用名称のみ付与してよい
- BGM長さ: `短・1メロ`／`中・2メロ`／`長・4メロ`（4／8／16小節。尺に加えメロディ・アレンジの区間展開）
- SE: カテゴリ → 用途、雰囲気。カタログ変更は再生／別パターンまで鳴らさない
- 用途変更時は雰囲気・長さ・音色イメージの既定を更新

#### 共有（ナビ右上）

- ライブラリに保存
- WAVを書き出して共有

### 8.4 画面遷移（概要）

```
ホーム
  ├─ BGM ─→ 制作画面（使う場所→用途・1画面）
  └─ SE  ─→ 制作画面（カテゴリ → 用途・1画面）
ライブラリ → 制作画面
制作 → 共有メニュー（保存／WAV）
```

### 8.5 アクセシビリティ

- Dynamic Type 対応
- 主要な操作に VoiceOver ラベル（「再生」「別パターン」「共有」等）
- 再生中は視覚的インジケータを表示
- 色だけに依存しない選択状態（チェックや太枠など）

### 8.6 空状態・エラー

|------|----------|

| 戦闘用ループ BGM 1 本以上を組み込める | 必須 |

## 14. リスクと対策

| リスク | 対策 |
|--------|------|
| 音が「おもちゃ」に聞こえる | プリセット調整と簡易マスタリングを早めに入れる |
| BGM メロディがランダム連打／似た出だしに聞こえる | 雰囲気別モチーフ辞書＋歩幅制約＋seed 直結の家族選択。詳細は 6.6 / SOUND_PLAN |
| BGM のループ継ぎ目が目立つ | 小節単位設計＋クロスフェード書き出し |
| ジャンル追加が UI だけ先行する | 「選べる＝実装済み」ルールとカタログ単一ソース |
| 選択肢が多すぎて迷う | MVPは少数。グループ化。既定値を強くする |
| 開発が UI に偏りエンジンが育たない | Phase 1–2 で Mapper＋エンジンを先に固める。3.5 もエンジン中心 |
| ストアでAIアプリと誤認 | 手続き生成である旨を説明文・アプリ内に明記 |
| サンプル音源の権利 | 初期は合成のみ。追加時はライセンス表を必須化 |

## 15. 用語集

| 用語 | 意味 |
|------|------|
| 手続き的生成 | 乱数とルールで波形・音符を組み立てる方式。学習モデル必須ではない |
| Intent | ジャンル・用途（`sceneId`）・雰囲気・長さ・音色など、ユーザーが選んだ制作意図 |
| Catalog | ジャンル／使う場所／用途などの選択肢と、それに紐づく生成テンプレの定義集合 |
| Mapper | Intent を Recipe に変換する純ロジック |
| Recipe | エンジンが音を生成するために必要なパラメータ一式 |
| シード | 乱数の初期値。同じ Intent＋シードなら同じ結果を目指す（用途・雰囲気等が同じ場合） |
| 別パターン | seed だけを変え、画面上の他条件を維持したまま別バリエーションを生成する操作 |
| 使う場所 | BGM の第1階層（画面／プレイ中／結果） |
| 音色イメージ | BGM の楽器プリセット選択（シンセリード／ピアノ等）。SE の「音色」スライダーとは別 |
| モチーフ | 反復・変奏の単位となる短いメロディ形（本製品ではおおむね2〜4小節） |
| MelodyComposer | Intent／Recipe からノート列を組み立てる純ロジック。雰囲気別モチーフ辞書・歩幅制約・長さ展開（1／2／4メロ）を含む |
| ループBGM | 終端と始端が自然につながるよう設計された伴奏 |
| 微調整 | 制作画面インラインのテンポ・ピッチ・リズム等（BGM）／高さ・音色等（SE） |
