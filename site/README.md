GitHub Pagesで公開する静的サイトです。`site/` 以下には、トップページ、プライバシーポリシー、利用規約、サポートページが含まれます。

## ページURL

独自ドメインのルートへ公開した場合のURLです。

- `/` — トップページ
- `/privacy/` — プライバシーポリシー
- `/terms/` — 利用規約
- `/support/` — サポート
